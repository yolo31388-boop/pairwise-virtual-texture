# 游戏内虚拟纹理与流式纹理系统

## 项目描述

游戏内虚拟纹理与流式纹理系统的bug修复项目。核心模块 `rendering/virtual_texture.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 虚拟纹理完全没做所有纹理都加载到内存
- 流式纹理完全没做只能预加载所有纹理
- 纹理压缩完全没做纹理都是未压缩的
- 纹理池完全没做纹理不会卸载
- 纹理LOD完全没做远处的纹理也用最高分辨率

## 运行测试

```bash
python -m pytest tests/test_virtual_texture.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
